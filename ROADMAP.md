RajClean Turbo Pro Roadmap

This roadmap describes planned improvements for RajClean Turbo Pro.

Roadmap items may change as development progresses.

Current Release

Version 8.2

- Interactive storage cleaner
- Internal storage scanning
- External storage scanning
- Duplicate file detection
- Junk and temporary file detection
- Preview before cleaning
- RajClean trash directory
- "--help" support
- "--version" support
- GPG-signed APT repository
- AArch64 package index support

Version 8.3

Planned

- Improve duplicate detection performance.
- Improve junk-file detection accuracy.
- Improve scan progress reporting.
- Improve handling of inaccessible Android directories.
- Improve external storage detection.
- Add safer file-move handling.
- Improve terminal output and error messages.

Version 8.4

Planned

- More advanced scan filters.
- Better temporary-file classification.
- Improved preview information.
- File size summaries.
- Cleaner scan results.
- Additional command-line options.

Future Releases

Possible Features

- Interactive scan filters.
- Exclusion lists.
- Configurable trash location.
- Restore files from RajClean trash.
- Automatic cleanup rules.
- Detailed cleanup reports.
- Better Android permission handling.
- Improved performance for large storage devices.
- Optional JSON output for scripting.
- Non-interactive cleaning mode.
- Shell scripting integration.

Package Repository

Future releases will continue to use the RajClean APT repository.

Each release should include:

- Updated Debian package.
- Updated "Packages" index.
- Updated compressed package index.
- Updated "Release" metadata.
- Updated repository checksums.
- New GPG signature.

Development Principles

Future development will prioritize:

1. Safety
2. Reliability
3. Performance
4. Compatibility
5. Simple user experience

RajClean should never sacrifice user data safety merely to make a cleaning operation faster.
