Code of Conduct

Our Commitment

We want RajClean Turbo Pro to be a welcoming, respectful, and constructive open-source project for everyone.

All contributors, maintainers, users, and community members are expected to participate respectfully.

Expected Behavior

Contributors should:

- Be respectful and professional.
- Communicate constructively.
- Welcome different viewpoints and experiences.
- Focus on technical issues rather than individuals.
- Provide useful and honest feedback.
- Respect the privacy and security of other contributors.

Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or personal attacks.
- Discrimination or hateful conduct.
- Threats or intimidation.
- Deliberate disruption of discussions or development.
- Publishing private or sensitive information without permission.
- Malicious code contributions.
- Sharing passwords, private keys, tokens, or other credentials.
- Any other conduct that is inappropriate for a professional open-source project.

Reporting Problems

If you experience or observe unacceptable behavior, report it privately to the project maintainer rather than escalating the situation publicly.

For security vulnerabilities, follow the instructions in "SECURITY.md".

Maintainer Responsibility

Project maintainers may remove comments, reject contributions, restrict participation, or take other reasonable action when necessary to maintain a safe and constructive project environment.

Scope

This Code of Conduct applies to project repositories, issues, pull requests, discussions, and other project-related communication spaces.

Enforcement

Maintainers are responsible for interpreting and enforcing this Code of Conduct fairly and consistently.

Actions may depend on the severity and circumstances of the violation.

Acknowledgment

By participating in the RajClean Turbo Pro project, contributors agree to follow this Code of Conduct.
