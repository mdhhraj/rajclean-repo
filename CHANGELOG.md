# Changelog

All notable changes to RajClean Turbo Pro are documented here.

## [8.2] - 2026-08-24

### Added
- Added `rajclean --help` command.
- Added `rajclean --version` command.
- Added short options `-h` and `-v`.
- Added proper command-line argument handling.
- Added source code to the repository.
- Published RajClean 8.2 as a Debian package.
- Updated APT repository package index.
- Added AArch64 package index support.

### Changed
- Updated application version from 8.1 to 8.2.
- Updated package metadata.
- Improved CLI usability.

### Fixed
- Fixed `rajclean --help` opening the interactive cleaner.
- Fixed `rajclean --version` opening the interactive cleaner.

## [8.1] - 2026-08-24

### Initial Release
- RajClean Turbo Pro initial repository release.
- Internal storage scanning.
- External storage scanning.
- Duplicate file detection.
- Junk and temporary file detection.
- Preview detected files.
- Move selected files to RajClean trash.
- Interactive terminal interface.

---

## Version Format

RajClean follows semantic-style version numbering:

`MAJOR.MINOR`

Example:

`8.2`
